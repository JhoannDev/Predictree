# Datos simulados

Aquí irá el **generador propio de datos simulados** de reservas del DoubleTree by Hilton Lima Miraflores
(script en Python con reglas y parámetros definidos por el equipo y una semilla fija para que
cualquiera regenere exactamente los mismos datos).

Los archivos que produzca el generador se guardan en `data/generados/` (no se suben a GitHub).
